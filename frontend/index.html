ARCHITECTURE & WORKFLOW

How DocuChain Operates

Three simple steps guarantee document provenance, tamper detection, and public trust without sacrificing personal privacy.

01

1. Client-Side Hash

Users select any digital document. The browser computes a 256-bit cryptographic SHA-256 fingerprint in local memory using the Web Crypto API. The actual document never leaves your machine.

02

2. Blockchain Anchor

The generated hash and document title are submitted to the Solidity smart contract via MetaMask. An immutable, timestamped record is permanently sealed into an Ethereum block.

03

3. Instant Verification

Anyone can verify a document by re-hashing it or providing the hash. The smart contract validates ownership, registration timestamp, and revocation state in milliseconds.
